# بيانات HotelPMS الافتراضية والتحكم بها

هذا الملف هو خريطة التشغيل للديمو؛ لا توجد بيانات افتراضية مخفية في الواجهة.

## مصادر البيانات

| النطاق | المصدر المعتمد | طريقة التعديل |
|---|---|---|
| الفندق الرئيسي، أنواع الغرف، الغرف، الضيوف والحجوزات | `hotelpms/scripts/seed_demo.py` | عدّل الثوابت `PROPERTY` و`ROOM_TYPES` و`GUESTS` ثم أعد بناء الديمو |
| المطعم، الصور، الأصناف، المخزون، التجارب والقاعات | `hotelpms/scripts/seed_showcase.py` | عدّل `POS` و`INGREDIENTS` و`EXPERIENCES` و`VENUES` |
| النصوص والبيانات السعودية ثنائية اللغة | `hotelpms/scripts/seed_arabic_demo.py` | عدّل خرائط التعريب والقيم السعودية هنا |
| حسابات الديمو وأدوارها وكلمات مرورها | `hotelpms/scripts/seed_users.py` | القائمة `USERS` هي المصدر الوحيد للحسابات الظاهرة في تسجيل الدخول |
| المستخدم الخدمي للحجوزات العامة | `GOVERNED_WRITER` في `seed_users.py` | غير ظاهر في الدخول ولا يملك كلمة مرور للديمو؛ لا تحذفه |
| اسم الفندق الاحتياطي في الواجهة | `DEMO_PROPERTY` في `frontend/src/lib/api.ts` | يستخدم فقط قبل أن يعيد الخادم الفندق المتاح للمستخدم |
| الوحدات المتاحة لكل فندق | حقل `enabled_modules` في مستند `Property` | تتحكم به شاشة الإعدادات؛ فارغ يعني جميع الوحدات |
| العملة والضريبة والرقم | حقول `currency`, `country`, `gstin`, `phone` في `Property` | الديمو مضبوط على SAR وضريبة 15% وأرقام تبدأ بـ `+966` |

## الحالة الحالية للموقع

- 3 منشآت سعودية، 9 أنواع غرف، 24 غرفة.
- 12 ضيفًا و12 حجزًا (يتضمن حجز فحص المسار العام `RES-2026-01105`).
- 10 تجارب، منفذا مطعم، 8 أصناف قائمة، و4 قاعات.
- 8 حسابات ديمو بشرية + مستخدم خدمي واحد `agent@hotelpms.local`.
- العربية هي لغة الديمو، ووضع الديمو مفعل.

## دورة إعادة الضبط

المهمة `hotelpms.scripts.reset_demo.scheduled` تعمل يوميًا الساعة 04:15 بتوقيت الموقع.
تمسح بيانات اللعب والجلسات ثم تستدعي بذور الديمو أعلاه. تحتفظ فقط بالحسابات
المعروفة والمستخدم الخدمي. لإعادة بناء موقع الديمو يدويًا:

```bash
bench --site hotelpms.yemenfrappe.com execute hotelpms.scripts.reset_demo.execute
```

الأمر محمي ويرفض العمل على أي موقع إنتاج غير معرف كساحة ديمو.
