# HotelPMS — إعادة التصميم v2 «واحة Oasis»

هوية وتجربة جديدتان بالكامل لنظام HotelPMS، مبنيتان على **مراجعة أفضل أنظمة PMS عالميًا** (Mews، Cloudbeds، Apaleo، Stayntouch — التفاصيل والمصادر في `pms-benchmark.md`) وعلى تحليل 62 لقطة من النظام الحالي.

**الهوية:** تيل زمردي عميق على قماشة عاجية دافئة + كهرماني مشمشي للانتباه، بخط **Alexandria** — بديل الكحلي/الذهبي السابق.
**التجربة:** طابور «يحتاج منك الآن» + خط زمني لليوم بدل اللوحات الجامدة، ولوح تفاصيل سياقي بدل التنقل بين الصفحات، وTape chart بسحب وإفلات وPopover، وPOS لمسي بلا تمرير.

## ملاحظات
- بيانات سعودية متسقة عبر الشاشات (نُزُل الرياض، 14 غرفة، الجمعة 4 سبتمبر 2026، VAT 15%) — نفس الرقم بنفس القيمة في كل مكان، عمدًا.
- الخط يُحمَّل من Google Fonts (Alexandria)؛ دون إنترنت يعمل بديل النظام تلقائيًا.
- التركيز على الشاشات المحورية بطلبكم؛ بقية الشاشات تُشتق من نفس المكوّنات والرموز في `design-system.md`.
