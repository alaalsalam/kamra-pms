# HotelPMS Design System — «واحة Oasis UI» v2.0

نظام التصميم الرسمي لواجهات HotelPMS بعد مراجعة أفضل أنظمة PMS عالميًا (انظر `pms-benchmark.md`). **يستبدل هوية v1 (كحلي/ذهبي) بالكامل.** الشاشات المرجعية: `redesign-screens/v2-*.html`.

**لماذا تغيّرت الهوية؟** الكحلي+الذهبي قالب مكرر في الضيافة ويميل للثِقل، وسوق الـPMS مشبع بالأزرق (Cloudbeds/Opera/Protel). الهوية الجديدة: **تيل زمردي عميق** (واحة/نخيل — هدوء وثقة وانتماء محلي غير مباشر) على **قماشة عاجية دافئة**، مع **كهرماني مشمشي** بجرعات دقيقة للانتباه والترحيب. النتيجة: منتج يبدو حديثًا ومميزًا فورًا في أي عرض بيع.

**المبادئ (مستمدة من الأفضل عالميًا):**
1. **الشاشة الأولى تجيب: ماذا أفعل الآن؟** — طابور مهام وخط زمني، لا مؤشرات جامدة (Mews).
2. **اللوح السياقي قبل التنقل** — التفاصيل تفتح جانبيًا فوق القائمة في معظم المهام (Mews Smart Panel).
3. **لون قائد واحد** — التيل للفعل والتنقل؛ كل الألوان الأخرى دلالات حالة حصرًا (Apaleo restraint).
4. **كشف التعقيد عند الطلب** — الافتراضي بسيط، والتفاصيل تتوسع بالنقر.
5. **اللمس والسرعة أولًا** — 48px في POS/الجوال، اختصارات، وأتمتة تحذف شاشات (إغلاق ليلي صامت).
6. **عربي أصيل** — RTL كامل، لغة واحدة في الشاشة، أرقام موحدة.

## 2) الخطوط والأرقام
- **الخط: Alexandria** (Google Fonts، أوزان 300–800) — عربي هندسي حديث بلاتيني متناسق مدمج؛ يمنح شخصية معاصرة مميزة عن كل المنافسين. البديل: `"Segoe UI", Tahoma`.
- الأوزان: 800 هيرو الضيف، 700 عناوين، 600 أزرار/تسميات، 500 نص متوسط، 400 نص، 300 ممنوع في الواجهات التشغيلية.
- السلم: display 32/44 · h1 25/36 · h2 15/24 (700) · body 13–13.5/22 · caption 11.5/18 (600) · micro 10.5/16 (600) · KPI 27/34 (700، tabular).
- الأرقام: **لاتينية موحدة** + `tabular-nums` في الجداول والمبالغ؛ خيار منشأة للأرقام المشرقية يطبَّق على النظام كله.
- العملة: «1,495 ر.س» (رمز الريال U+20C1 عند توفر دعم الخط، بتراجع تلقائي).
- «0» حقيقي دائمًا؛ «—» لغير المتوفر مع tooltip. الهواتف والأكواد داخل `bdi dir=ltr`.
- التواريخ: «الجمعة 4 سبتمبر 2026» + 24 ساعة؛ هجري سطرًا ثانويًا اختياريًا.

## 3) الشكل والمقاسات
- مسافات قاعدة 4: `4…64`؛ حشوة البطاقة 18–20؛ فجوة الشبكة 14–18.
- الأنصاف: `md 12` أزرار/حقول · `lg 16` بطاقات · `xl 22` ألواح/Modal · `pill 999` chips وأشرطة المخطط والبحث العام.
- الظلال: `sm 0 1px 2px rgba(27,36,32,.05)` · `md 0 6px 20px .07` · `lg 0 18px 44px .13`. الزر الأساسي يحمل ظلًا تيليًا خفيفًا `0 4px 12px rgba(14,122,108,.24)`.
- التخطيط: Sidebar فاتح (عاجي) 248px يمين + Topbar شفاف 62px (بحث حبة دواء 380px + تاريخ + إشعار + CTA) + محتوى ≤ 1180px.
- الأيقونات: Outline بسمك 1.7، مقاسات 16/18/20.
- نقاط القطع: 390 / 768 / 1024 / 1280 / 1440.

## 4) قواعد RTL/LTR (كما v1 — ملزمة)
Logical Properties فقط؛ الأيقونات الاتجاهية تنعكس؛ الزمن يتقدم يمين←يسار في المخططات؛ المدى «5 ← 7 سبتمبر»؛ عزل bdi للأرقام المختلطة؛ Drawer من الجهة المقابلة للتنقل؛ لغة واحدة في الشاشة؛ منتقي تاريخ عربي (لا mm/dd/yyyy).

## 5) المكوّنات الأساسية
- **Sidebar فاتح:** مجموعات مهامية (التشغيل / الضيوف والإيراد / الإدارة)، عنصر نشط `teal-50` + شريط 3px تيل، عدادات pill (الساخنة كهرمانية)، أسفله بطاقة المنشأة + المستخدم.
- **Global Search حبة دواء** في المنتصف تعمل كموزّع أوامر (Ctrl+K): نتائج ضيف/حجز/غرفة مع أفعال مباشرة.
- **Queue Card (يحتاج منك الآن):** أيقونة ملونة + عنوان + سطر سياق + زرّان (رئيسي ممتلئ). ثلاث بطاقات كحد أقصى مرئية.
- **Tile (KPI):** تسمية → رقم 27px → دلتا؛ Hero tile بتدرج تيلي وميتر كهرماني؛ كلها قابلة للنقر مع سهم hover.
- **Day Timeline:** صفوف (وصول/مغادرة/تدبير/مطعم) على مسار 8:00–18:00، أحداث كحبوب ملونة بالدلالة، خط «الآن» كهرماني بعلامة.
- **Data Table:** رؤوس micro خافتة بلا خلفية ثقيلة، صف hover عاجي، الصف المحدد `teal-50` + شريط جانبي تيل، ترقيم، تحديد جماعي.
- **Contextual Panel (اللوح السياقي):** عرض 372px، رأس عاجي (هوية + شارات + tabs داخلية)، جسم KV + ملخص مالي + أزرار مكدسة، يلتصق أسفل الـTopbar. هو الطريق الافتراضي للتفاصيل.
- **Tape Chart:** أشرطة pill بأفاتار؛ مقيم صلب تيلي-داكن، مؤكد `teal-100`، مبدئي متقطع، OOO مخطط أحمر؛ VIP بحلقة كهرمانية؛ صف إشغال حراري؛ **صينية غير المُسند** فوق الشبكة بحد كهرماني متقطع + اقتراح آلي؛ Popover إجراءات على الشريط.
- **POS:** رأس `teal-900` بشرائح الفواتير؛ ثلاث ألواح بلا تمرير صفحة؛ بطاقات أصناف بخلفيات باستيل هادئة؛ الطاولة الحالية كهرمانية؛ زرا «للمطبخ» (تيل داكن) و«الدفع» (كهرماني) 56px؛ سطر غير مُرسل بخلفية `amber-50`.
- **Booking Engine:** هيرو تحريري (عنوان 40px بكلمة مميزة تيلية + كولاج 3 بطاقات مستديرة)، بطاقة بحث طافية، بطاقات غرف أفقية والمختارة بإطار تيلي، ملخص لاصق، شارات دفع محلية، تذييل `teal-900`.
- **Buttons:** Primary (تيل ممتلئ) · Tonal (`teal-50`) · Secondary (أبيض محدد) · Ghost · Amber (تحصيل/انتباه) · Danger outline. ارتفاعات 32/40/50.
- **الحالات الخمس** (تحميل Skeleton، فارغ، خطأ، لا-صلاحية بقفل وطلب، نجاح Toast داكن بزر تراجع كهرماني) — إلزامية لكل شاشة.

## 6) الوصولية WCAG AA
كما v1: تباين ≥ 4.5:1 (كل أزواج هذا الملف محسوبة)، Focus حلقة `rgba(14,122,108,.16)` بسمك 3، أهداف لمس ≥ 44/48px، الحالة لا تُنقل باللون وحده، `prefers-reduced-motion`، تكبير 200% بلا كسر.
